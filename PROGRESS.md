# Readlet — progress

This file tracks the work for v0.1. Read `PROJECT_BRIEF.md` for the scope and
`docs/decisions/` for the decisions.

Legend: `[x]` done · `[~]` in progress · `[ ]` to do

Current target: **v0.1 working in desktop Chrome (Chromium).** Firefox, Safari and mobile come
after the Chrome milestone.

## M0 — Repository setup

- [x] git, pnpm workspace, TypeScript 6 (strict, `noUncheckedIndexedAccess`), Biome
- [x] Package skeletons: `@readlet/core`, `@readlet/pdf`, `@readlet/react`, `examples/vite-react`
- [x] Decision notes 0001–0004
- [ ] LICENSE (MIT) and NOTICE (pdf.js Apache 2.0) at root and in each package
- [ ] Changesets config
- [ ] GitHub Actions CI (typecheck, lint, unit, e2e on Chromium/Firefox/WebKit, bundle size)

## M1 — Core model (pure, Node-testable, `core/src/model`)

- [ ] Public types: `DocumentSource`, `PageInfo`, `TextRange`, `TextPosition`, `PageRect`,
      `Highlight`, `OutlineItem`, `ReadletError`, `ViewMode`, `ZoomMode`
- [ ] `DocumentBackend` / `BackendDocument` / `BackendPage` interfaces
- [ ] Typed event emitter
- [ ] Text normalisation (`text-normalise.ts`): page string plus item offsets
- [ ] Text item geometry (same maths as the pdf.js text layer)
- [ ] `TextRange` helpers: normalise order, compare, clamp, JSON validation
- [ ] `rangeToText`, `rangeToRects` (with an injected text measurer)
- [ ] Layout maths: page offsets, visible range with buffer, fit-width / fit-page scale
- [ ] Unit tests, coverage ≥ 90% on `core/src/model`

## M2 — PDF backend (`@readlet/pdf`)

- [ ] Load from URL, `ArrayBuffer`, `Uint8Array`, `Blob`, `File`, with progress
- [ ] Inline worker from Blob URL; `workerSrc` / `workerPort` escape hatches
- [ ] Typed errors: `invalid-pdf`, `password-required`, `network`, `worker-failed`
- [ ] Page render to canvas (cancellable), text content in page coordinates
- [ ] Outline with resolved page indexes; link annotations (internal and external)

## M3 — Core DOM (`core/src/dom`)

- [ ] `ReadletDocument` + `loadDocument`
- [ ] `PageView`: canvas (DPR capped at 3, max canvas pixels), stale-render guard, release
- [ ] `TextLayer`: spans + separators, DOM ↔ offset mapping, end-of-content trick
- [ ] Link layer: internal navigation, external links in a new tab
- [ ] `Viewport`: scroll and page modes, virtualisation, zoom, rotation, `goToPage`, events
- [ ] `SelectionManager`: `getRange`, `setRange`, `rangeToRects`, `rangeToText`, `change`
      (rAF debounced), copy handler, capture/restore around layout changes
- [ ] Keyboard navigation and aria labels

## M4 — React adapter (`@readlet/react`)

- [ ] `useDocument`, `useViewport`, `useSelection`
- [ ] `<Viewer>`, `<Page>`, `<HighlightLayer>`
- [ ] StrictMode safe (double mount), no leaks on unmount

## M5 — Example app (`examples/vite-react`)

- [ ] Minimal unstyled viewer with mode, zoom, rotation, outline, page nav, selection readout
- [ ] Test hooks on `window` for Playwright

## M6 — Browser tests (Playwright, Chromium first)

- [ ] Fixture PDFs (freely licensed, generated by `scripts/make-fixtures.mjs`)
- [ ] Drag-select a sentence: `rangeToText` equals clipboard
- [ ] Drag across page 3 → 4: `start.page = 2`, `end.page = 3`
- [ ] Zoom 100% → 200% with a selection: range unchanged
- [ ] Serialise → reload → `setRange` → same rects
- [ ] Double click a word: range covers exactly that word
- [ ] Load from URL / ArrayBuffer / Blob / File; progress and error events
- [ ] Virtualisation: 1,000 pages, heap < 200 MB
- [ ] Load/destroy 500 pages × 10: heap back to baseline ± 20%
- [ ] Rotation, zoom modes, outline, links, page mode navigation
